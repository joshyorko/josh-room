# Logical JAT v1 descriptor

`schemas/logical-jat-v1.schema.json` defines the closed JSON contract for one complete Room Store recovery point. `josh_room.logical_jat.LogicalJat` validates the same fields at the Python boundary and provides canonical JSON and a stable SHA-256 digest. Canonical JSON is UTF-8, sorted by key, compact, and limited to 65,536 bytes.

The required workspace reference identifies one complete restic snapshot by repository, format, snapshot, and tree IDs. `parent_logical_jat_id` and `workspace.parent_snapshot_id` are optional lineage/performance hints only. Parsing or restoring the selected descriptor does not resolve either parent field.

The three component slots are always present and may be `null`. A populated slot has a field-specific shape and its own exact restic snapshot reference. RCCA and Homebrew references carry an archive digest, size, and fixed capsule member basename. RCCA also carries validated artifact/specification digests, platform, RCC version, and a safe relative `robot.yaml` path. Hauler content carries a fixed archive identity and closed digest/media-type references; raw registry names and URLs are not recorded. Component snapshot references must use the descriptor's workspace repository ID and repository format; their snapshot and tree IDs may differ because each component is captured independently.

IDs and producer labels use bounded opaque tokens; hashes use lowercase SHA-256 hex. The descriptor does not accept workspace paths except the fixed relative root `.`; credentials, arbitrary metadata, unknown fields, non-integer numeric counters, and non-v1 formats are rejected. `source` carries only optional Git commit/dirty state. `producer` carries Josh Room/restic versions and the supported source/restore platform matrix (`linux-x64`, `win32-x64`). An optional `origin_room_id` preserves the original Room binding when a same-Dimension copy reuses a snapshot under a new Room ID.

This module defines and validates the plaintext contract only. It does not encrypt, publish, update a catalog, or implement restore. The selected Dimension's existing age operation remains responsible for protecting a descriptor before storage.
