## Known gaps at baseline

- Host scout has Hauler, RCC, zstd, and tar; `go` and `age` are not installed.
- JAT has no stable `--json` build/restore/inspect output, so the Josh Room
  wrapper must record process metadata around the existing exact command rather
  than parse decorative output.
- Real R2 credentials are unavailable and public-push authorization was not
  granted; those are explicit later gates.
