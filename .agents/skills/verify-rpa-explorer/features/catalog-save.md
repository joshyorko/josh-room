# Native Catalog Save

## Sub-features
Seeded synthetic Git child, authenticated destination, review and Save.

## How to get to it (user POV)
Save Catalog → projects → a → Continue → destination → review.

## Driving it with RCC Browser
Use the exact provider image and pinned MinIO. After normal controller acquisition, fixture/enroll provisions a private native keyring. Select only the observed Synthetic Catalog Pilot destination. Inspect review, then click Save catalog and assert the actual success notification.

## Gotchas
Enrollment is fixture setup, not UI enrollment proof. Missing provider is a failed precondition. A click or plan is not Save. Confirmation cancellation with audited write control is separately unqualified.
