# Managed workspace check

## Sub-features
Exact VSIX installation, Node activation and normal managed controller response.

## How to get to it (user POV)
Command palette → Josh: Check Workspace.

## Driving it with RCC Browser
Use command joshRoom.checkWorkspace and assert its semantic report. Original five-entry valid fixture evidence remains under docs/receipts/rpa-pilot.

## Gotchas
The larger discovery fixture intentionally has a nonportable name and cannot expect the same valid result. An editor TCP socket is not activation proof; no host-Python substitution or runtime patch.
