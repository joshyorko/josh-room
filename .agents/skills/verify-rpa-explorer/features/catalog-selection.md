# Catalog selection

## Sub-features
Folder choice, suggestions/browse, single/bulk choices, Git settings and cancel.

## How to get to it (user POV)
Command palette → Save Catalog Room; or New Room → Configure Catalog Room.

## Driving it with RCC Browser
verify_selection chooses two independent synthetic siblings and asserts the settings screen. Adaptive batches choose from actual returned rows.

## Gotchas
Monaco virtualizes rows and replaces inputs asynchronously. Empty suggestions are not global absence. Known enclosing-folder Select All rejection is a seeded control, not a new discovery.
